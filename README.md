# 🧠 Interactive Quiz App

A responsive and interactive multiple-choice quiz web application built with **HTML**, **CSS**, and **JavaScript**.

## 🎯 Features

- 📝 Multiple-choice questions
- ✅ Instant feedback on answers
- 📊 Score tracking
- 🔄 Randomized questions (optional)
- 📱 Responsive design
- 📈 Progress bar or visual indicator
- 🏁 Final score summary


## 🛠️ Tech Stack

- **HTML** – Markup structure
- **CSS** – Styling and layout
- **JavaScript** – Quiz logic and interactivity
